# ChiChi Club


몬치치가 Windows 바탕화면 위를 걸어 다니고, 멀리 있는 친구와 배구를 하는 데스크톱 앱입니다. 트레이 아이콘을 누르면 게임 허브가 열립니다.


## 설치


[Windows 설치파일 다운로드](https://github.com/daepang1/chichi-club/releases/latest) · [모든 릴리스](https://github.com/daepang1/chichi-club/releases)


처음 한 번 설치하면 이후 새 버전을 자동으로 내려받고 앱 종료 시 적용합니다. 경기가 끝난 뒤 설정에서 바로 적용할 수도 있습니다. 자동 업데이트는 Setup 설치형에서 지원합니다.


## 함께 놀기


- 486종 전체 인형을 이름 검색과 7개 분류로 골라요. 고른 인형은 바탕화면과 경기장에서 함께합니다.
- 트레이 아이콘을 눌러 `친구와 방 만들기`에서 초대 링크를 복사합니다.
- 친구도 앱을 설치하고 `친구 방에 참가하기`에 링크를 넣습니다. 두 사람이 준비하면 시작합니다.
- 혼자 연습에서는 AI와 배구할 수 있습니다.
- 이동: ← → / A D, 점프: ↑ / W / Space, 스파이크: X / J
- 허브 열기: Esc / Ctrl+Alt+C, 표시·숨기기: Ctrl+Alt+H


방장의 앱이 실행 중일 때 인터넷 방이 유지됩니다. 공유기 포트포워딩은 필요하지 않습니다.
